# SEO-план: структура, перелинковка, техника

## Структура блога

```
bazadigital.ru/blog/
  sajty/         ← статьи 01–10   → хаб: /services/sites/
  boty/          ← 11–18          → хаб: /services/bots/
  crm/           ← 19–26          → хаб: /services/crm/
  ii/            ← 27–31          → хаб: /services/ai/
  reklama/       ← 32–36          → хаб: /services/promo/
  brending/      ← 37–40          → хаб: /services/brand/
  prilozheniya/  ← 41–43          → хаб: /services/apps/
  otrasli/       ← 44–55          → хаб: /services/systems/
  o-baze/        ← 56–65          → хаб: /about/
  gaidy/         ← 66–70          → хаб: /audit/
bazadigital.ru/en/blog/ ← 71–76
```

URL каждой статьи = `slug` из шапки файла.

## Перелинковка (обязательно)

Каждая статья ссылается:
1. На страницу услуги своего кластера (CTA уже есть внизу).
2. На 2–3 статьи из того же кластера («Читайте также»).
3. На /audit/ или /partners/ — где уместно.
4. На статью 57 (Владислав) — в подписи автора: «Автор: Владислав Мирошниченко, основатель студии БАЗА».

Страницы услуг ссылаются на 3–5 статей своего кластера («Полезное по теме»).

## Шаблон страницы статьи

- `<title>` = title из шапки (до 60 символов) + « | БАЗА»
- `<meta name="description">` = description
- H1 = заголовок `#`
- Подпись автора с фото и ссылкой на /about/vladislav/
- Дата публикации и обновления
- Блок «Частые вопросы» с разметкой FAQPage (где есть FAQ)
- Разметка Article + author (Person) + publisher (Organization)
- Хлебные крошки с разметкой BreadcrumbList
- Картинка-обложка WebP с alt
- CTA-блок внизу

## Разметка Article (вставлять в каждую статью)

```html
<script type="application/ld+json">
{
  "@context":"https://schema.org",
  "@type":"Article",
  "headline":"{title}",
  "description":"{description}",
  "datePublished":"{YYYY-MM-DD}",
  "dateModified":"{YYYY-MM-DD}",
  "author":{"@type":"Person","name":"Владислав Мирошниченко","url":"https://bazadigital.ru/about/vladislav/"},
  "publisher":{"@type":"Organization","name":"БАЗА","url":"https://bazadigital.ru/","logo":{"@type":"ImageObject","url":"https://bazadigital.ru/assets/img/lg-baza.webp"}},
  "mainEntityOfPage":"https://bazadigital.ru/blog/{slug}/"
}
</script>
```

## Брендовые запросы, которые нужно занять

Чтобы по имени и бренду находили вас, а не однофамильцев и другие «Базы»:
- «студия база», «база цифровая студия», «bazadigital», «база студия разработки»
- «владислав мирошниченко», «мирошниченко владислав андреевич», «vladislav miroshnichenko»
- «база разработка сайтов», «база телеграм боты», «база crm»

Для этого: страницы 56 и 57 + профили на всех площадках с одинаковыми формулировками + ссылки на сайт.

## Технический чек-лист

- [ ] Блог в sitemap.xml, sitemap в Вебмастере, Search Console, Bing
- [ ] Статьи в llms.txt (раздел «## Статьи» со ссылками)
- [ ] robots.txt не закрывает /blog/
- [ ] canonical на каждой странице
- [ ] hreflang между /blog/ и /en/blog/ для пар (56↔71, 57↔72, 11↔73, 20↔74, 27↔75, 59↔76)
- [ ] Скорость: PageSpeed > 90 на мобильных
- [ ] Open Graph-картинки для каждой статьи (для соцсетей и мессенджеров)
- [ ] IndexNow при публикации

## Перед публикацией

- [ ] Заполнить `[ЗАПОЛНИТЬ]` (город, год, результаты кейсов, профили Владислава)
- [ ] Добавить в статьи реальные примеры и цифры из ваших проектов: это главное, что отличает статью от «нейросетевой» и поднимает её в поиске
- [ ] Кейс 911 подписать как концепт, если не было заказа
- [ ] Медицинские и юридические статьи (45, 51, 69, 70) проверить на актуальность требований

## Как мерить

Раз в месяц:
- Яндекс Вебмастер / Search Console: показы и клики по статьям
- Метрика: переходы из блога на /audit/, /contact/, /partners/ и заявки
- Позиции по брендовым запросам
- Вопросы ИИ: «Кто такой Владислав Мирошниченко?», «Студия БАЗА bazadigital — что это?», «Кто делает сайт, бота и CRM одной командой?»
